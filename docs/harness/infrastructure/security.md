# 安全规范

> 技术栈：C# 5 / .NET Framework 4.x / Windows Forms / GDI+；本地单机桌面工具，无服务端、无账户体系。
> 更新时间：2026-11-19

## 安全边界

本工具不联网、不监听端口、不持有数据库与账户，**不存在网络鉴权、会话与密钥管理**。安全关注点集中在：

1. 本地文件读写边界（输入只读、输出不覆盖、临时文件可清理）。
2. 不可信输入校验（用户拖入/命令行传入的图片路径与文件内容）。
3. 依赖与构建来源（当前零第三方依赖）。
4. 外部进程启动（用户确认后打开结果文件）。

## 输入校验

- 路径来源：GUI 拖放/文件选择框、命令行 argv。命令行参数必须能处理含空格路径（引号缺失时按现状报错退出）。
- 文件类型：按扩展名白名单 jpg/jpeg/png/bmp/gif/tif/tiff（`ImageUtil.AllowedExts`）；扩展名不等于内容安全，仍需在解码阶段校验。
- 文件内容：`ImageUtil.Load` 解码失败抛 `InvalidDataException`；尺寸小于 8×8 判为无效。
- 输入原图只读：不得修改、移动或删除源文件。
- 新增任何外部输入（如新参数、目录扫描规则）时，沿用「白名单 + 解码校验 + 失败跳过不中断整批」的现有策略。

## 输出与文件系统安全

- 原子写入：先写同目录 `.esw_<8位GUID>.tmp`，成功后 `File.Move` 到目标；失败删除临时文件。
- 不覆盖：目标已存在时自动改名（`_2`…`_199`，仍冲突追加时分秒）。
- 输出目录不存在时自动创建；不写入系统目录或提权路径。
- 临时文件名使用随机 GUID，避免并发或残留冲突。

## 外部进程启动

- 仅在用户点击"现在打开检查"时调用 `Process.Start` 或 `explorer.exe /select,<path>`。
- 传入路径必须是本次实际生成的文件路径，不得拼接未校验的外部输入。
- 打开失败时回退为资源管理器定位，不重试不可信程序。

## 密钥与凭据

- 本工具不需要账号、Token、密钥或配置文件；不得在源码、日志或示例中引入凭据。
- 如未来增加云端能力，凭据必须通过环境变量或系统凭据存储注入，不写入源码与发布目录。
