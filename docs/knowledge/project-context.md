# 项目上下文

- **project-mode**: brownfield
- **业务域**: 通用域（独立运行的 Windows 桌面效率工具）
- **架构风格**: 单体桌面应用（单进程、单 exe、WinForms GUI + CLI 双入口，进程内分层）
- **技术栈**: C# 5 / .NET Framework 4.x（Win10/11 自带 4.8）/ Windows Forms / GDI+ / 自研 OOXML + ZIP 写入 / 无数据库
- **判定依据**:
  - brownfield: 当前仓库已有可运行的 v1.3 业务代码（`Source/`、`dist/PaperToWord.exe`）与既有系统约束，技术方案按兼容演进设计评审。

## 评审侧重

- **brownfield**：评审以现有系统兼容性、影响范围、迁移成本为主。
- 后续需求不得默认推翻现有行为（裁切几何、页序规则、原子落盘、零第三方依赖等）；如需变更，应在 Spec 中显式说明影响范围与迁移方式。

## 项目定位

把手机横版拍摄的试卷图片沿中线裁成左右（或上下）两片，每片按打印最优方式排成 A4 页面并打包成标准 `.docx`，让重新打印的试卷字号足够大、版面不浪费。

## 运行形态

- **GUI 模式**：无参数启动，拖入/选择图片 → 调整顺序与参数 → 生成 docx → 弹窗询问是否打开。
- **CLI 模式**：参数含图片路径或 `--out` 时进入；`--out=路径` 或 `--out 路径` 指定输出；缺省输出到首图目录下 `yyyyMMdd-.docx`；退出码 1 表示失败。
- **运行环境**：Windows 10/11，依赖系统自带 .NET Framework 4.8，离线可用，无需 Office/WPS。
