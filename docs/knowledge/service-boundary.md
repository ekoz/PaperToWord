# PaperToWord：把横版试卷照片裁成大片幅 A4 页，产出一份可直接打印的 Word

## 核心定位

`本地桌面工具` `试卷裁页排版` `docx 原子落盘`

> 独立运行于 Windows 单机的领域工具（单进程、单 exe、GUI + CLI 双入口），不属于网关/编排层，也不提供任何对外能力。核心业务对象是一次运行内的「处理清单 → 裁片 → A4 页 → 输出文档」。唯一主写产物是本机磁盘上的一份 .docx，无数据库、无网络、无外部服务依赖。

## 核心职责

- **试卷图片整理**：把用户提供的图片汇总为有序、去重、可人工纠偏的处理清单，清单顺序即输出页序。
- **裁切与版面适配**：按裁切方式与位置把一张卷面切成 1–2 片，并决定每片落在纵向还是横向 A4 上、是否两片同页。
- **图片加工与清晰度控制**：EXIF 方向纠正、按 DPI 档位缩放，统一输出为白底 JPEG。
- **Word 文档生成与安全落盘**：自建 OOXML/ZIP 组装标准 .docx，经临时文件原子改名，重名不覆盖。
- **双入口与结果反馈**：GUI 完成导入、预览、参数、执行与日志；CLI 完成无界面批量转换并返回退出码。

## 显性边界

- **不处理试卷内容本身**：不做 OCR、文字识别、纠错、去污、版式还原或答案识别；源图片只读，不修改、不移动、不删除。裁剪之外的内容加工由用户自行完成。
- **不处理打印**：不调用打印机、不生成 PDF、不保证 Word/WPS 之外的排版呈现；实际打印在 Word/WPS 中由用户完成。
- **不持有持久化数据**：无数据库、无配置文件、无历史记录；处理清单、裁切配置、裁片、A4 页均只存在于本次运行内存，结束即释放。试卷原图归属用户，输出 docx 归属本工具但仅落在本地文件系统。
- **不提供多用户与权限模型**：无账户、角色、鉴权与并发协作；能力边界完全由操作系统文件权限决定，同一时刻只允许一个生成任务。
- **不提供接口与服务端能力**：无 HTTP/RPC/MQ、不监听端口、不发布或消费任何事件；不作为其他系统或流程的服务方。
